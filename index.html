Projects

社員管理システム (Employee Management System)

Java / Swing / MySQL / JDBC

社員情報を管理するためのデスクトップアプリケーションです。 管理者（ADMIN）と社員（STAFF）の2つのロールに分かれ、それぞれ異なる機能を提供します。

主な機能

  • ログイン画面: 管理者（ADMIN）または社員（STAFF）を選択してログイン
  • 管理者機能: 全社員の一覧表示、名前で検索、社員情報の更新（部署変更）、社員の削除
  • 社員機能: 社員ログイン、新規社員登録、給与計算

学んだこと

  • Java Swingでの画面作成（JFrame, JPanel, JButton, JOptionPaneなど）
  • ActionListenerを使ったイベント処理
  • JDBCを使ったデータベース操作（SELECT, INSERT, UPDATE, DELETE）
  • PreparedStatementで安全にSQLを実行する方法
  • 入力チェック（バリデーション）の大切さ
  • クラス分け（設計）を意識するとコードが読みやすくなること

課題と解決方法

課題1: データベースに接続できないことがあった。
解決方法: GetConnectionクラスを作って接続処理を1か所にまとめ、try-catchでClassNotFoundExceptionとSQLExceptionを分けて処理した。

課題2: 勤務時間が空のまま計算するとエラーになった。
解決方法: working_hour.isEmpty()でチェックし、「Please enter Working Hour」とメッセージを出して処理を止めるようにした。
